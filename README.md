# 🌸 國小四年級社會（四上）全冊手繪心智圖互動筆記系統 ✏️

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live%20Demo-brightgreen?logo=github)](https://github.com)
[![Curriculum](https://img.shields.io/badge/108課綱-國小四年級社會-orange)](https://www.naer.edu.tw/)
[![License](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Art Style](https://img.shields.io/badge/風格-彩色鉛筆粉彩繪本風-pink)](#)

本專案依據臺灣教育部 **108 課綱南一／康軒／翰林版教材** 精心編製，將國小四年級上學期社會科的 **4 大單元全冊總覽** 與 **10 個小單元深度精讀**，全面轉化為深受學生喜愛的**「手繪可愛風彩色鉛筆粉彩繪本心智圖系統」**。

---

## 🌟 核心特色 (Key Features)

- 🎨 **14 張 AI 原生手繪心智圖**：以奶油水彩紙為底，搭配柔和粉彩筆觸、彩虹標題緞帶、擬人化腮紅可愛元素與繁體中文標籤。
- 🧩 **四象限嚴謹教學架構**：每張圖卡精確劃分 4 大區域，涵蓋課綱核心概念與在地化生活情境。
- 💡 **朗朗上口押韻口訣**：全冊收錄 14 首押韻記憶口訣，幫助小學生課堂朗誦秒記重點。
- 🛡️ **易錯迷思避雷針**：精準剖析段考最常混淆之易錯觀念，強化思維辨析。
- ⭐ **折疊式隨堂快問快答**：點擊按鈕即時展開解答，適合課堂互動提問與學生自主複習。
- 🔍 **高清圖片燈箱放大 (Modal Zoom)**：點擊任一心智圖卡即可放大全螢幕檢視細節。
- 📋 **AI 繪圖 Prompt 一鍵複製**：每張圖卡皆提供標準 Prompt，方便複製至 Midjourney / DALL-E / Gemini 重新微調。
- 🖨️ **友善列印樣式**：內建 `@media print` 專屬樣式，按下 `Ctrl + P` 即可直接列印為學生紙本複習單。
- ⚡ **純前端零依賴**：單檔免伺服器架構，直接開啟 `index.html` 或透過 **GitHub Pages** 免費全球託管！

## 📸 心智圖單元總覽 (Curriculum & Mindmaps)

### 🌟 4 大單元全冊總覽 (Major Unit Overviews)
1. **第 1 單元：交通與訊息 (`TRANSPORTATION & COMMUNICATION`)**  
   陸地鐵公路運輸、河海船運變遷、藍天航空與智慧數位訊息傳播。
2. **第 2 單元：地圖上的家鄉 (`HOMETOWN ON THE MAP`)**  
   地圖四要素（圖名/方位/圖例/比例尺）、八方位判定、各式主題地圖與電子導航。
3. **第 3 單元：認識家鄉景觀 (`HOMETOWN LANDSCAPES`)**  
   自然地形奇景（月世界/清水斷崖）、歷史人文古蹟（城門/書院/寺廟/洋樓）與活化再生。
4. **第 4 單元：家鄉的節慶 (`HOMETOWN FESTIVALS`)**  
   漢人歲時節俗、原住民族歲時祭儀、地方特色觀光盛事與現代感恩紀念日。

### 🌈 10 個小單元深度精讀 (10 Sub-Units)
- **1-1 陸地的運輸**：鐵道百年演變、高鐵一日生活圈、捷運綠色通勤、公路物流與偏鄉幸福巴士。
- **1-2 船運與空運**：古今河港轉型、海運多元船隻、離島藍色公路與空中急難醫療後送。
- **1-3 訊息的傳播**：古今通訊演變、智慧醫療照護、國家防災避難告警與數位假訊息查證。
- **2-1 閱讀地圖認識家鄉**：家鄉定義、地圖四大要素、四方位與八方位精準判定法。
- **2-2 家鄉的地圖**：等高線地形圖、行政區圖、觀光圖、空拍衛星影像圖與實地探究規劃。
- **3-1 家鄉的景觀**：大自然風化侵蝕奇景、湖泊水岸休閒、歷史古蹟洋樓與景觀興衰。
- **3-2 家鄉景觀與生活**：景觀多元功能、踏查四步驟（人/時/名/特）、老建築活化與高美濕地生態。
- **4-1 家鄉的傳統節慶**：漢人歲時節俗（春節/清明/端午/中元/中秋）、原民祭典（飛魚/豐年/戰祭/嬰兒祭）。
- **4-2 家鄉的特色節慶活動**：產業觀光（木雕節/天燈節）、宗教遶境（媽祖節/王船祭）、西方與新住民節慶。
- **4-3 發現生活中的節日**：感恩身分節日（親師兒童）、國家紀念日（元旦/國慶）與全球理念（地球日/人權日）。

## 🚀 部署至 GitHub Pages 教學 (How to Deploy to GitHub)

### 方法一：使用自動化腳本一鍵推播 (推薦)

本專案已為您準備好 `deploy_to_github.bat`（Windows）與 `deploy_to_github.sh`（Mac/Linux）：

1. 在 GitHub 上點擊 **New repository** 建立一個新的公開存放庫（例如命名為 `grade4-social-mindmap`）。
2. 在本專案根目錄雙擊執行 `deploy_to_github.bat`。
3. 依提示貼上您的 GitHub Repo 網址（例如 `https://github.com/您的帳號/grade4-social-mindmap.git`）。
4. 腳本會自動完成 `git init`、`git add`、`git commit` 並推送到 `main` 分支！

---

### 方法二：手動 Git 指令部署

開啟終端機（PowerShell 或 Bash），在專案目錄下依序執行：

```bash
# 1. 初始化 Git 存放庫
git init

# 2. 加入所有檔案
git add .

# 3. 建立首次提交
git commit -m "feat: 初次發布國小四年級社會手繪心智圖互動系統"

# 4. 綁定 GitHub 遠端存放庫 (請將 URL 換成您的 repo)
git remote add origin https://github.com/您的帳號/grade4-social-mindmap.git

# 5. 推送至 main 分支
git branch -M main
git push -u origin main
```

---

### 方法三：直接在 GitHub 網頁上傳 ZIP 包

1. 解壓縮已為您打包好的 `github_deploy_package.zip`。
2. 在 GitHub 建立好新 repository 後，點擊 **Uploading an existing file**。
3. 將解壓縮出的所有檔案與資料夾（包含 `index.html` 與 `images/`）直接拖拉上傳並 Commit 即可。

---

## 🌐 啟用 GitHub Pages 免費公開網站

專案推送到 GitHub 後，請按照以下步驟開啟線上網站：

1. 前往您在 GitHub 上的專案頁面，點擊右上方的 **Settings**（設定）。
2. 在左側選單點擊 **Pages**。
3. 在 **Build and deployment** 下方的 **Branch**：
   - 選擇 **`main`** 分支。
   - 資料夾選擇 **`/(root)`**。
   - 點擊 **Save**（儲存）。
4. 等待約 1～2 分鐘重新整理頁面，頂部即會出現您的專屬公開網址：
   > 🔗 `https://您的帳號.github.io/grade4-social-mindmap/`
5. 現在全校師生、家長與學生都可以隨時透過手機、平板或電腦直接瀏覽互動心智圖！
